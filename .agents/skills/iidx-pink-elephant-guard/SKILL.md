# IIDX Pink Elephant Guard

現在確定した契約だけで自立する完成物へ整える。[AGENTS.md](../../../AGENTS.md)と今回のIssue・仕様を適用する。

## 適用場面

会話に却下・削除・訂正があり、Issue、仕様書、README、利用手順、PR本文、UI文言などを仕上げるときに使う。旧案を記録する必要がある比較、変更履歴、レビュー、障害分析にはそのまま適用しない。

## 現在の目的から組み直す

1. 現在伝える目的・仕様・挙動、却下された履歴、残す必要のある記録を内部で分ける。
2. 現在の契約・読者・必要な記録だけを材料にする。旧案の「書かないもの一覧」を本文の設計へ戻さない。
3. 語句を消すだけで済ませず、見出し・説明・例を現在の目的から組み直す。却下案を機械的にNon-scope、将来課題、設定項目へ移さない。
4. 見出し、冒頭、注記、表、例、操作ラベルを確認し、旧案の同義語・否定形・削除理由・旧案のためだけの空節も取り除く。

Issue契約に必要なNon-scope・受け入れ条件、保存/PWA/起動の制約、安全・アクセシビリティ表示、実際の差分、未実施検証、未解決事項は保持する。正本の矛盾を隠して解決しない。

完成稿だけの依頼には、旧案の検査結果を添えず完成物を返す。
